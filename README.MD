 # GIT
 ### Comando iniciales 
 - **git init** para inciar git en la carpeta 
 - **git add .** para agregar todos los cambios 
 - **git add archivo o carpeta especifica** para agragar una carpeta o aarchivo especifica y no todo 
 - **git commit -m "xxxxx"** para crear un commit y darle una descripción entre las comillas 
 - **git status** verificar el estado de los archiovos que estan listos para subir al repositorio y los que no 
 - **git config --global user.name "xxxx"** cambiar la configuración del nombre del usuario "tu usuario de github"
 - **git config --global user.email "xxx"**  cambiar la configuración del email del usuario "tu email de github"
 - **git log** verificar los logs o las acciones que se han realizado y quien las ha realizado
